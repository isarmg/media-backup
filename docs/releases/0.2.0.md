# media-backup 0.2.0

Server/Web 与移动客户端分别锁定独立的 Server/Agent Foundation 0.6.0。

当前管理员界面、备份业务页面、文件安全接口和 ABI 2 移动 FFI；C 头文件按 Cargo.lock 中的实际 Foundation 源码检查，无同级目录依赖。

本次是现有改造工作的阶段收尾，不代表《更新手册》全部完成。不保留旧代码、旧名称或旧版本合同的兼容路径；当前版本部署应使用本版本发行说明和状态合同。

Rust Foundation 依赖锁定完整 Git revision 与精确版本；Web Foundation 依赖使用 v0.6.0 发行 tarball 与 lockfile 完整性值，不依赖同级源码目录。发布以精确提交的 CI 和实际发行制品验收结果为准。

正式移动发行必须提供已有 Android 发行证书对应的 PKCS#12 及密码，并通过原生平台验证。缺失签名配置时不能用调试 APK 或新证书替代正式发布。
