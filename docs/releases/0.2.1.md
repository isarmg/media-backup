# Media Backup 0.2.1

本次发布收录当前管理 Web 的统一外观、中英文适配和登录校验修复。

- 登录页与顶部工具栏支持简体中文/英文切换，并记住语言偏好；取消切换不改变当前语言。
- 必填校验不再弹出浏览器气泡；提示位于密码框下方、登录按钮上方的第五行，保持字体与六行内容块样式。
- 登录提示支持键盘提交、错误字段焦点和无障碍描述；无效输入不会发送登录请求。
- 保留统一顶部导航、图标工具栏、实例表格及消费者自定义外观能力；不恢复诊断功能或版本号展示。
- 不改变管理员认证、会话和权限边界，不提供旧版本兼容代码。

发布制品绑定精确 Git 提交和当前版本；以附件校验和及制品内身份为准。历史标签和 Release 保持不可变。
## 移动端制品

Android 为使用既有发布证书签名的 arm64 APK；证书 SHA-256 为 `0cfc2811d48cdeab3e6d857029d879e001ab9531c06784b4d48d15a847771421`。iOS 提供原发布流程支持的未签名设备构建，不代表可直接安装或 App Store 发布；安装仍需用户自己的 Apple 签名与 provisioning。

应用版本更新为 0.2.1，移动状态代为 `media-backup-mobile-v0.2-r2`；FFI ABI 2 与 wire revision 1 保持不变。使用新的数据库/暂存目录，不读取旧状态，不包含迁移工具。
